## 📖 About the Project

The **Registration Form System (TrilhaBackEnd-Desafio-3)** is a frontend application designed to simplify and automate the candidate enrollment process. Built with a focus on usability and responsive design, the platform guides users through an intuitive application flow, capturing necessary data efficiently and securely.

Whether used for job applications, school enrollments, or event registrations, the core architecture is built to be scalable and highly accessible to all users.

## ✨ Key Features

- **Automated Workflow**: Streamlines the application and selection process.
- **Responsive Design**: Flawless interface across desktop, tablet, and mobile devices.
- **Form Validation**: Client-side validation ensuring clean and accurate data entry.
- **Accessible UI**: Designed with web accessibility best practices in mind.
- **Secure Data Handling**: Clean architecture ready for secure backend integrations.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Custom styling, responsive layouts, and animations.
- **JavaScript**: Dynamic interactions and client-side form validation.
- **Git**: Version control.

## 💻 Running Locally

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FelipeAlmadaa/TrilhaBackEnd-Desafio-3.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd TrilhaBackEnd-Desafio-3
   ```
3. **Open the project:**
   Simply open the `index.html` file in your favorite browser, or use a tool like VS Code Live Server for hot reloading.
